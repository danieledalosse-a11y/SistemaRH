Todas as abas (tabs) do SistemaRH devem ter emoji antes do texto, seguindo o padrão já estabelecido no módulo de Uniformes.

**Why:** Usuária pediu consistência visual — o sistema usa emojis como ícones nas abas do modal de entrega (📦 Kit / 👕 Uniforme / 🦺 EPI) e quer manter o mesmo padrão em todas as telas.

**How to apply:** Ao criar ou editar qualquer aba (`sec-tab`, `tab`, subtab), incluir um emoji representativo antes do texto. Referência de emojis já em uso:
- 📦 Kit / caixas / estoque
- 👕 Uniforme / roupa
- 🦺 EPI / proteção
- 📋 Listas / catálogo / itens
- 📊 Painel / dashboard
- ⚙️ Configurações
- 📅 Datas / calendário
